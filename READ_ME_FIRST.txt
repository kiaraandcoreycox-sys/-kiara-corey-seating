KIARA & COREY — WEDDING SEATING WEBSITE

UPLOAD ONLY index.html to the root of your GitHub repository to publish the site. It contains the floral artwork and 86-guest list.

Optional: upload guests.csv to the same location to override the baked-in guest assignments. When table assignments change, replace guests.csv without changing the URL or QR code.

To publish using GitHub Pages: Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.

Do not upload this ZIP itself into GitHub. Extract the files first.

Privacy note: this public website includes guest names and table assignments.
